# Estudo

Este repositório contém uma coleção de exercícios e projetos desenvolvidos como parte de estudos em diversas tecnologias. É importante notar que este repositório foca principalmente nas etapas iniciais da minha jornada de aprendizagem. Embora eu continue a estudar e aplicar outros conceitos e tecnologias mais avançadas (como Spring, PostgreSQL, entre outros) em projetos, muitos deles não estão presentes neste repositório. Minha aprendizagem se estende para além do que está documentado aqui.

## Conteúdo do Repositório:

### CrV-HTML5-CSS3
Contém diversos exercícios e pequenos projetos de desenvolvimento web focados em HTML5 e CSS3. Os tópicos abordados incluem:
- **Módulos MD3, MD4, MD5**: Estruturas básicas de páginas web, design responsivo, tabelas, iframes, formulários, e técnicas de layout modernas como Flexbox e Grid CSS.
- **Desafios e Exemplos**: Projetos práticos para aplicar conceitos de estilização e estrutura de conteúdo.

### Java
Uma coleção de projetos e exercícios em Java, abrangendo desde fundamentos da linguagem até tópicos mais avançados:
- **SantanderBootcamp**: Exercícios relacionados a um bootcamp, incluindo aplicações de console básicas (e.g., ContaTerminal), conceitos de controle de fluxo, e tratamento de erros.
- **Udemy**: Projetos e exemplos de cursos da Udemy, cobrindo:
    - Programação Orientada a Objetos (POO): Encapsulamento, classes, objetos.
    - Fundamentos da Linguagem: Estruturas de dados, lógica de programação.
    - Tópicos Avançados: JPA/Hibernate, Generics, Lambdas, Stream API, tratamento de erros, e padrões de projeto.

### MySql
Contém scripts e projetos relacionados a banco de dados MySQL:
- **banco-relacional**: Scripts SQL para criação de tabelas, inserção e manipulação de dados, focados no aprendizado de modelagem e operações em bancos de dados relacionais.
- **JDBC**: Projetos Java que demonstram a conectividade e interação com bancos de dados MySQL utilizando JDBC (Java Database Connectivity), incluindo operações CRUD (Criar, Ler, Atualizar, Deletar).

### React
Um projeto inicial de React para estudo e prática do framework:
- **primeiro-projeto**: Uma aplicação React básica, configurada com `create-react-app` (ou similar), explorando:
    - Componentes React: Criação e uso de componentes funcionais.
    - Manipulação de Eventos: Resposta a interações do usuário.
    - Gerenciamento de Estado: Uso de `useState` e `props` para gerenciar dados entre componentes.
    - Listas e Renderização Condicional: Exibição dinâmica de conteúdo.

Este repositório serve como um portfólio de estudos e uma referência rápida para os conceitos aprendidos e aplicados.
